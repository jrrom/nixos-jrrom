#+TITLE: Oracle Cloud

* Initial Steps
- Create an Oracle Cloud account, do the setup and all that
- Generated =oracle.tf=
- Signed in with OCI, config to /home/<user>/.oci
- Tofu init, plan and apply

** Note
We can use =tofu output= to get the public ip.

* nixos-anywhere

#+begin_src bash
nix run github:nix-community/nixos-anywhere -- \
  --flake .#oracle \
  --build-on remote \
  --generate-hardware-config nixos-generate-config ../parts/hardwareOracle.nix \
  --target-host ubuntu@$(tofu output -raw public_ip)
#+end_src
